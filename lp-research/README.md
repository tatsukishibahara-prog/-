## 1. SmartHR ― BtoB SaaS（人事労務クラウド）

- URL: https://smarthr.jp/
- ターゲット: 人事・労務の担当者と、導入を決める経営層

### 構成（上から順）
1. **ファーストビュー**: 「〇〇を簡単に」系のベネフィットを書いたキャッチコピー、登録社数などの実績数字、CTA（資料請求／お問い合わせ）
2. **導入企業ロゴ**: 業界や規模の違う企業のロゴを並べ、社会的証明にする
3. **課題の提示**: 紙の書類・ハンコ・転記作業など、現場の不満を言葉にする
4. **機能紹介**: 入社手続き、年末調整、従業員データベースなどを、UIのスクリーンショットと一緒に見せる
5. **導入効果**: 工数削減率などの数字（**前提条件を注記**している）
6. **導入事例**: 企業名・担当者・具体的な効果
7. **セキュリティ・サポート体制**: BtoBで決裁を通すときの不安をつぶす
8. **料金の案内**、**FAQ**
9. **クロージングCTA**: 資料請求（フォームの入力項目は少なめ）

### 良いところ
- 「8万社以上」は「事業所の登録まで済んだテナント数」、「約88%削減」は「従業員1,000名規模の企業を想定して試算」というように、**数字の定義を注記している**。BtoBでは誇大表現に見えないことが信頼につながる。
- 各セクションに「資料請求」ボタンがあり、途中まで読んだ人も取りこぼさない。
- 情報量は多いが、機能をタブや小見出しで分けているので読みやすい。

### 真似するときのポイント
実績数字には **定義・時点・算出の前提** を必ず添える。

## 2. BASE FOOD ― D2C食品（完全栄養食サブスク）

- URL: https://basefood.co.jp/
- ターゲット: 健康は気になるけれど、食事に時間をかけたくない会社員

### 構成（上から順）
1. **ファーストビュー**: 商品のシズル写真と「1食で必要な栄養素がとれる」というベネフィット、初回割引のオファー、CTA
2. **共感・課題の提示**: 忙しくて食事が偏る、栄養が足りない、といった悩み
3. **商品の特徴**: 栄養素、おいしさ、手軽さ
4. **ラインナップ**: パン・パスタ・クッキーなど、味や種類のバリエーション
5. **口コミ・メディア掲載・累計販売数**
6. **比較**: 普段の食事や他の選択肢と栄養価を比べる
7. **定期便の説明**: 割引率、「いつでも解約・スキップできる」こと、配送の頻度
8. **FAQ**、**最後のオファー＋CTA**

### 良いところ
- ファーストビュー、CTAの文言、価格の見せ方を **A/Bテストで細かく最適化** している。
- 定期購入が事業の中心なので、LPのゴールは初回購入でも、**続けてもらえるか（LTV）** を前提に訴求を設計している。
- 「解約できる」ことを隠さずに見せ、**申し込む心理的ハードルを下げている**。

### 真似するときのポイント
サブスク型の商品では、「やめやすさ」はマイナス要素ではなく **申し込む理由** になる。

## 3. chocoZAP ― フィットネス（コンビニジム）

- URL: https://lp.chocozap.jp/main-01/
- ターゲット: ジム未経験の人、運動が続かなかった人

### 構成（上から順）
1. **ファーストビュー**: 「月額2,980円（税抜）」を大きく表示、「RIZAPが作った」という権威づけ、入会CTA
2. **気軽さの訴求**: 着替え不要・靴のままOK・1日5分から、など
3. **設備の紹介**: マシンだけでなく、脱毛・セルフエステなど「ジム以外」の設備
4. **店舗数・アクセス**: 店舗検索、「家や職場の近くにある」ことを伝える
5. **アプリ・サポート**: 体組成計やアプリとの連携
6. **料金の詳細**、**入会キャンペーン**
7. **FAQ**、**最後のCTA**

### 良いところ
- **価格そのものを主役にしている**。「ジムは高い・きつい」という思い込みを、ファーストビューだけで崩している。
- 「RIZAP」ブランドを権威として使いながら、ストイックな印象をあえて消し、**ハードルの低さ** を前面に出している。
- 「ジムのLP」という枠を超えて、生活を便利にするサービスとして見せている。

### 真似するときのポイント
価格に強みがあるなら、それを **ファーストビューの一番大きな文字** にする。

## 4. ビズリーチ ― 人材（ハイクラス転職）

- URL: https://www.bizreach.jp/lp/official/pc/
- ターゲット: 年収の高い層、今すぐ転職するつもりはない潜在層も含む

### 構成（上から順）
1. **ファーストビュー**: 利用者の多い年代の **転職後の平均年収** などの実績、「実際の求人を見る」CTA
2. **スカウトの仕組み**: 企業やヘッドハンターから直接スカウトが届く
3. **実績・求人の例**
4. **第三者機関の評価**（ページ後半）
5. **最後のCTA** → 登録フォーム（Google／Apple IDなどでの登録にも対応）

### 良いところ
- **ページがとても短い**。情報を詰め込まず、登録という1つの行動に集中させている。
- CTAが「登録する」ではなく **「実際の求人を見る」**。ユーザーが得をする行動として言い換え、登録への抵抗を減らしている。
- 会員の8割以上が「自分の市場価値を知るため」に登録しているというデータがある。LPも「今すぐ転職しなくてもいい」という気軽さで潜在層を取り込んでいる。

### 真似するときのポイント
ブランドの認知度が高い、または広告経由で目的がはっきりした人が来るなら、**短いLPのほうがCVRが上がる** ことがある。

## 5. RIZAP ENGLISH ― 教育（パーソナル英会話）

- URL: https://www.rizap-english.jp/lp/e-05
- ターゲット: 仕事で英語が必要になった社会人（TOEICや英会話）

### 構成（上から順）
1. **ファーストビュー**: 「結果にコミット」のブランドメッセージ、期間（最短2か月）と成果の約束、無料カウンセリングのCTA
2. **課題の提示**: 英会話スクールに通っても話せるようにならない理由
3. **独自メソッド**: 専属トレーナー、目標に合わせたカリキュラム、自習の管理
4. **ビフォーアフター**: TOEICスコアの伸びや、受講者の声
5. **コース・料金**、**返金保証などの安心材料**
6. **カウンセリングの流れ**、**FAQ**
7. **最後のCTA**（カウンセリング予約）

### 良いところ
- 高額な商品なので、いきなり購入させず **無料カウンセリング** をCVにしている（2段階で成約させる）。
- 「なぜ今まで失敗したのか」を先に説明するので、読み手が **「自分のせいではなかった」と納得** してからメソッドの話に入れる。
- 数字で示すビフォーアフターと、保証の組み合わせで、リスクがないと感じさせる。

### 真似するときのポイント
単価が高い商材は、LPのゴールを「購入」ではなく **「相談」** にすると成約までの流れを作りやすい。

## 5つのLPに共通すること

1. **ファーストビューで「誰に・何が得られるか・今申し込む理由」がわかる**
2. **社会的証明**（ロゴ、数字、口コミ、第三者の評価）を早めに見せる
3. **不安をつぶす要素**（FAQ、保証、解約のしやすさ、セキュリティ）を後半に置く
4. **CTAを複数回置き**、文言をユーザーが得をする言葉にする（「求人を見る」「無料で相談」など）
5. **商材に合わせてLPの長さを変える**: 高単価・検討期間が長い → 長尺、認知度が高い・判断が簡単 → 短尺

## LPを作るときの基本テンプレート

```
1. ファーストビュー（キャッチコピー／実績数字／CTA）
2. 社会的証明（ロゴ・数字）
3. 課題への共感
4. 解決策・商品の特徴
5. 根拠（機能、メソッド、比較）
6. 事例・口コミ
7. 料金・オファー
8. 不安の解消（FAQ・保証）
9. クロージングCTA
```
